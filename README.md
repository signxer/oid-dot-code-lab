# OID 码图实验室

离线研究工具：对用户自行提供的 Windows 菲林程序调用局部 x86 函数，生成二代码或三代码候选图。**结果未经原程序 GUI 输出逐像素对照，也未经点读笔解码验证。** 不代表与小彼恩毛毛虫兼容，不能生成 BNL 或绑定音频。

## 原理与范围

通过静态分析定位码值转换和绘制函数，在隔离的 Unicorn 虚拟内存中模拟这些局部函数；不会启动整个 Windows 软件。后处理将采集的 64×64 图案周期性铺满输出图像。原软件没有随本项目发布，用户需自行提供原始 ZIP 或菲林程序。支持的菲林程序 SHA-256：`44db3732933fab38be70e202937f0896c92d3c78fe7f39fcc50814578cc561f8`。

本项目代码使用 MIT 许可；此许可不适用于用户提供的原始工具及其数据。原工具声明仅限学习研究、禁止商业用途。请自行核查许可与适用的分发条件。

## 安装与使用

需要 Python 3.9+、Pillow 和 Unicorn。安装依赖：

```bash
python3 -m pip install 'Pillow>=10,<13' 'unicorn>=2.1,<3'
python3 oid_lab.py --source /path/to/通用码铺码工具.zip --type 2 --code 1001 --output oid2.png
python3 oid_lab.py --source /path/to/通用码铺码工具.zip --type 3 --code 1001 --output oid3.png
```

默认输出 1536 × 1536 的单色 PNG，元数据为 1200 dpi，按该分辨率约 32.512 mm 见方。请勿缩放或插值；打印驱动可能重新处理点阵。不同码值产生不同图案不代表编码正确。
